# Zstandard encoder - Monthly progress report

In the first month of the project we merged 70 PRs spanning more than 500 commits, working primarily on cleaning up the code base and incrementally making more functionality safe.

This cleanup proces, the 2nd milestone "LLM-assisted code cleanup", is the bulk of the work of the software changes to the encoder codebase. At the time of writing, 342 out of a total of 640 functions of the encoder are safe.

See the [README](README.md) for the deliverables and approach of the project.
