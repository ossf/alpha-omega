# Erlang Ecosystem Foundation Update — July 2026

## Basic Auth Deprecation

Hex basic authentication has been deprecated, announced via a blog post. This
was made possible by the OAuth2 Device Grant work completed as part of this
engagement.

* [Hex.pm Blog: Deprecating Basic Auth](https://hex.pm/blog/deprecating-basic-auth)

## Rebar3 OAuth2 Support

hex_core 0.19.0 has been released with the core CLI auth support and is already
used in Mix via Hex 2.5.0. The rebar3 and rebar3_hex PRs are complete and
awaiting merge.

* [erlang/rebar3#3008](https://github.com/erlang/rebar3/pull/3008)
* [erlef/rebar3_hex#361](https://github.com/erlef/rebar3_hex/pull/361)

## Engagement Conclusion

This update concludes the Hex.pm security audit engagement with Alpha-Omega.
